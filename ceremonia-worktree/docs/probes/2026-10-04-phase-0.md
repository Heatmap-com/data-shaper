# Phase 0 probes — 2026-10-04

Read-only probes against the three pilots (3199, 3207, 3228), run by
`scripts/probes/run-probes.mjs` plus focused follow-ups. No writes, no DDL.
Decision records live in `docs/decisions/` (one per plan §12 Phase 0 row).

## P1 — `udp_custom_events` / `journey_custom_map` payload shape (blocks P6)

`udp_custom_events` columns:

```
idsite Int32, idsitehsr Int32, device_type Int32, event_id Int32,
event_count Int32, event_type String, idvisit Int64, idloghsr Int64,
server_date Date32, server_time DateTime64(3), date String, hour String
```

`journey_custom_map` is the same shape (UInt types). **There is no
properties/JSON column.** The plan's §6.1 fallback applies: one event name
per state, properties encoded in `event_id`. Volume on the pilots since
2026-06-01: **zero rows in both tables** — no custom events are emitted on
the pilots today. Decision: D-01.

## P2 — Browser and visitor-id columns (H06, H27)

`udp_hsrce_visits` carries `config_browser_name`, `config_browser_version`
(both Nullable(String)) → H06 browser cut is feasible from L1.
There is **no visitor id** on visits. `udp_hsrce_pageviews.visitor_id`
(Nullable String) exists but is unique per visit — on 3199 for
2026-09-28..10-04, `uniqExact(visitor_id)` = `uniqExact(idvisit)` = 26,144.
It is a per-session token, not a cross-session key → Q10's default
confirmed. Decisions: D-02 (H06 available), D-03 folded into D-02 record
(H27 missing/partial per Q10).

## P4 — `udp_conversions.idorder` shape (Q7)

On the pilots, `idorder` is a **numeric string, 13–14 digits** (e.g.
`7111095386283`), distinct per order. It is not Shopify `order.name`
(`#1234`) and not a GID; it is a plausible Shopify **numeric order id**.
Match rate against `ae_src_order` cannot be measured until a Shopify token
exists (Q1) — the probe answer is "join candidate identified, rate unknown".
Decision: D-05.

`group_recording_id`, `event_href`, `time_on_page`, `pageview_click_count`

Filterable by page, device, date, duration, click count → H17 available.
Decision: D-06.
