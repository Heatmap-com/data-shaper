# D-09: retention on `ae_src_*` and output tables (plan §12 P0 row 9; Q12)

**Answer (operator):** not yet answered.

**Decision (Q12 default):** source-landing tables (`ae_src_*`) get a
400-day `TTL` on their partition key (enough for 90-day credit cohorts plus
two 30-day windows plus history), output tables (`ae_dataset_row`,
`ae_strategy_card`, `ae_page_analysis`, `ae_site_analysis`,
`ae_requirement_status`) get **no TTL** — card history (H26) reads them
across batches. The TTL clauses ship in the Phase 2 DDL and are part of
`ddl-lint`'s checks. If the operator sets a different retention, it is a
DDL change in the same release as a `standards.json` note, never a
post-hoc `ALTER … DELETE`.
